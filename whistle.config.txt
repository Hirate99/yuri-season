# YuriSeason 本地开发代理规则（whistle）
#
# 用途：本地 bun dev 页面的公开 API 全部走线上（https://i-yuri.com），
#        admin 接口（/api/admin/*）保留本地（需要本地 token + 本地 D1 写库）。
#
# 用法：
#   1. 启动 whistle：npm i -g whistle && w2 start
#   2. 浏览器/系统代理指向 whistle（默认 127.0.0.1:8899）
#   3. 打开 http://localhost:8899/ 规则面板，粘贴本文件内容
#
# 注意：
#   - 仅代理浏览器发起的请求；SSR 首屏（workerd 内 fetch）不走代理，仍用本地 D1
#   - 打开 http://localhost:3000/ 后客户端请求会落到线上数据

^http://localhost:3000/api/(?!admin(?:/|$))(.*)$ https://i-yuri.com/api/$1
^http://127.0.0.1:3000/api/(?!admin(?:/|$))(.*)$ https://i-yuri.com/api/$1
